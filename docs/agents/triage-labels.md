# Triage Labels

The five canonical triage roles used by engineering skills (to-issues, triage, diagnose, code-review, etc.):

| Role        | Label              |
|-------------|--------------------|
| New         | `status: new`      |
| Assigned    | `status: assigned` |
| In Progress | `status: in-progress` |
| Review      | `status: review`   |
| Done        | `status: done`     |

Additional priority labels:

| Priority | Label            |
|----------|------------------|
| Critical | `priority: critical` |
| High     | `priority: high`     |
| Medium   | `priority: medium`   |
| Low      | `priority: low`      |
