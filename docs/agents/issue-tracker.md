# Issue Tracker

Issues are tracked on GitHub at [Cacahouetes/nutty-panel](https://github.com/Cacahouetes/nutty-panel/issues).

## Labels

The project uses the standard GitHub labels plus these custom labels for agent orchestration:

| Label              | Purpose                                             |
|-------------------|-----------------------------------------------------|
| `ready-for-agent` | Ready for an agent to pick up and implement         |
| `spec`            | Requires spec analysis before implementation        |
| `triage`          | Needs triage discussion                             |
| `good first issue`| Beginner-friendly issues                            |
| `bug`             | Bug fixes                                           |
| `enhancement`     | New features                                        |
| `documentation`   | Docs improvements                                   |
| `refactor`        | Code refactoring                                    |
| `backend`         | Backend-specific work                               |
| `frontend`        | Frontend-specific work                              |
| `infra`           | Infrastructure/Docker work                          |
| `security`        | Security-related issues                             |

## Triage Labels

| Role            | Label                |
|----------------|----------------------|
| New            | `status: new`        |
| In Progress    | `status: in-progress`|
| Review         | `status: review`     |
| Blocked        | `status: blocked`    |

## Issue Template

Use this template when creating GitHub issues via skills:

```
[COMPONENT] Brief description

## Problem
What the user is experiencing.

## Expected
What the user expected to happen.

## Steps to Reproduce
1. ...
2. ...
3. ...

## Environment
- Nutty Panel version: ...
- OS: ...
- Browser: ...
```
