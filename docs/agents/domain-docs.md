# Domain Docs

## Context Files

Domain language lives in `docs/agents/CONTEXT.md` as a single-file glossary.

## ADRs

Architecture Decision Records live in `docs/adr/` as numbered Markdown files.

## Consumer Rules

- Read `docs/agents/CONTEXT.md` for domain vocabulary before naming concepts or writing tests.
- Read relevant ADRs in `docs/adr/` before introducing or changing conventions in those areas.
- When referencing domain concepts, use the exact terms from `CONTEXT.md`.
